# JPEG_PARS

CLI-утилита для пакетной сортировки JPEG-чертежей по визуальному сходству.

## Что делает

- принимает папку с `.jpg` / `.jpeg`;
- считает комбинированный score сходства `1..100`;
- группирует изображения в кластеры по заданному порогу;
- раскладывает результаты по папкам `group_001`, `group_002`, ...;
- сохраняет `report.json` с метаданными и score между элементами группы.

## Почему Python

Python здесь дает лучший баланс:

- быстро собрать рабочий CLI;
- удобно обрабатывать 500+ файлов локально;
- легко донастроить алгоритм под специфику чертежей;
- не нужен отдельный runtime кроме Python.

## Установка

## Запуск

```powershell
jpeg-pars `
  --input "C:\data\drawings" `
  --output "C:\data\drawings_sorted" `
  --similarity 82
```

Если entrypoint недоступен:

```powershell
python -m jpeg_pars.cli --input "C:\data\drawings" --output "C:\data\drawings_sorted" --similarity 82
```

## Аргументы

- `--input` путь к папке с изображениями
- `--output` папка для результатов
- `--similarity` порог сходства от `1` до `100`
- `--mode` `copy` или `move`, по умолчанию `copy`
- `--recursive` искать изображения рекурсивно
- `--min-group-size` минимальный размер группы для отдельной папки

## Как работает score

Итоговый score строится из нескольких признаков:

- `pHash` для общей формы изображения;
- `dHash` для локальной структуры линий;
- overlap edge-map для контуров чертежа;
- сходство горизонтальных и вертикальных проекций.

Это дает более стабильный результат на технических схемах, чем один hash.

## Интерпретация порога

- `90-100`: почти одинаковые чертежи, мелкие отличия
- `75-89`: очень похожие варианты
- `60-74`: одна и та же схема с заметными правками
- `40-59`: частично похожие
- `1-39`: слабое сходство

Начинать обычно стоит с `75-85`.
